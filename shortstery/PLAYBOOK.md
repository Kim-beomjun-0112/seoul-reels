# 숏스터리 제작·운영 규칙 (2026-11-27 확정)

모든 새 숏스터리 영상(쇼츠·3분 쇼츠·롱폼)은 아래 규칙으로 만든다.
전체 분석 문서: https://claude.ai/artifact/7d8bJmPAFHUqkRbj57c23o

## 주제 고르기 (3개 중 2개 이상)
- 이름만 들어도 아는 유명 미스터리인가
- 한 장면으로 그릴 수 있는 충격적인 상황이 있는가
- 끝에 "여러분은 어느 쪽?"을 물을 수 있게 가설이 2개 이상인가
- 잘 된 계열(실종, 고대 문명, 괴물·UFO)을 우선, 터진 주제는 1주 안에 같은 계열 후속

## 제목
- 앞: 장면·숫자 / 뒤: 유명한 이름. 예) "영하 30도, 텐트를 찢고 맨발로 도망친 9명… 댜틀로프 고개 사건"
- 답을 미리 알려주는 말 금지: "풀린", "밝혀진", "총정리", "알아보자". "진실"은 앞부분이 강할 때만.
- 끝에 #미스터리 #shorts

## 대본 구조 (60~90초)
| 구간 | 할 일 |
|---|---|
| 티저 0~1.5초 | 가장 기이한 장면 + 짧은 큰 자막 |
| 훅 1.5~4초 | 숫자+상황 한 문장, 배경 설명 없이 |
| 배경 4~15초 | 언제·어디·누가, 3문장 안 |
| 전개 15~45초 | 5초마다 새 사실, "그런데/문제는/더 이상한 건"으로 15초마다 꺾기 |
| 반전 45~60초 | 가장 이상한 단서 1개 |
| 가설 60~75초 | 과학적 설명 vs 남는 의문 |
| 끝 3초 | 두 갈래 질문 + 첫 문장으로 자연스럽게 이어지는 말(반복 재생) |
- 인물·연도가 많은 주제는 줄이거나 핵심 1~2명만
- 쇼츠에서는 "구독하세요"를 말로 하지 않음(롱폼 끝에만)

## 업로드·운영
- 쇼츠 하루 3~4개, 4~5시간 간격, 새벽 2~6시 제외, 예약 업로드
- 각 쇼츠의 관련 동영상 = 같은 계열 롱폼
- 계열 재생목록에 추가: 흔적 없이 사라진 사람들 / 고대 문명의 수수께끼 / 아직 아무도 찾지 못한 보물과 저주 / 괴물·UFO·설명할 수 없는 현상 / 풀리지 않은 사건과 암호 (+ 숏스터리 정주행)
- 인스타·스레드 = 유튜브 공개 +1시간 (queue.json)

## 기준값 (8주 뒤 채널 중앙값으로 교체)
- 계속 시청함 70%+ 좋음 / 55% 미만 위험
- 평균 조회율 100%+ 좋음 / 70% 미만 위험
- 구독 조회 1천 회당 4명+ 목표
- 좋아요율 3%+ 목표
